# Selenium Hybrid Reusable Framework

A **reusable Selenium automation framework** built with **Java, Selenium WebDriver, TestNG, Maven, and Page Object Model (POM)**.

Designed as a flexible foundation for web automation projects, with the core framework setup already in place. Simply add your **Page Classes, test cases, test data, and project-specific validations** to start automation without building the framework from scratch.

### 🛠️ Tech Stack

**Java | Selenium WebDriver | TestNG | Maven | POM | Hybrid Framework**

### ✨ Key Features

* ♻️ Reusable and maintainable framework structure
* 🧱 Page Object Model (POM)
* 🔄 Hybrid framework approach
* 🧪 TestNG-based test execution
* 📦 Maven dependency management
* 🔧 Easy to extend for new projects
* 📊 Supports scalable test automation

### 🚀 How to Reuse

Clone the repository:

```bash
git clone https://github.com/pawanrewatkar/selenium_hybrid_reusable_framework.git
```

Use the existing framework setup and add your project-specific:

```text
Page Classes
Test Cases
Test Data
Locators
Assertions
```

### 🎯 Goal

To provide a **ready-to-use, scalable, and maintainable Selenium automation foundation** that helps QA engineers start building automated tests quickly without setting up the framework from scratch.
